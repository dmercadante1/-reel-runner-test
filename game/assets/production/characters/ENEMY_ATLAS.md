# Gothic Horror enemy atlas

`enemy_atlas.png` is a 512×768 production raster atlas using 128×128 cells.

Rows / frame offsets:
- skeleton: 0–3
- ghoul: 4–7
- vampire: 8–11
- monster: 12–15
- werewolf: 16–19
- ghost: 20–23

All six are production raster enemies. There is no knight in the Gothic Horror roster.
