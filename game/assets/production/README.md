# Production Raster Assets

This directory is the source of truth for the authored raster rebuild of MAN WITH A MOVIE CAMERA — Level 1: GOTHIC HORROR.

Production art only. No programmer-art SVGs, procedural character drawings, or visible collision geometry belong here.

Structure:
- `characters/` — cameraman and enemy sprite sheets
- `environments/` — parallax backgrounds, playable masonry, foreground layers
- `fx/` — capture beam, particles, fog, fire, light and atmospheric raster effects

All assets target the locked 640×360 logical game resolution and nearest-neighbor presentation defined in `game/ART_DIRECTION.md`.
