MAN WITH A MOVIE CAMERA — GOTHIC HORROR

Open Gothic-Horror-Playable.html in a desktop browser and press ENTER THE COURTYARD.
Arrows or A/D move. Up or W jumps. Hold SPACE or C to capture. P pauses, R restarts.

This is a separate rebuilt candidate, not the old GitHub Pages deployment.
All artwork and Phaser are included: the HTML needs no asset downloads.

assets/ contains 14 validated PNG files and SHA-256 manifest.
src/ contains maintainable JavaScript modules.
sources/ contains complete original conversation artwork used for extraction.
tools/prepare_assets.py re-extracts assets; tools/bundle.py creates HTML from exact bytes.
tests/ contains actual rendered-browser tests.
evidence/ stores screenshots and machine-readable test results.

Not yet verified in Safari/WebKit or on a physical iPhone.
The scene uses a complete raster backdrop and separate raster masonry, not all five promised environment layers.
The art/animation quality is still subject to review; source design boards are not finished animation sheets.
