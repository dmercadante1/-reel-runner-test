## Findings established by actual file checks

All 45 tracked main files were inventoried and hashed. A local Git index reproduced the exact main tree hash. All 45 files in the real Pages artifact (Actions run 34412274190, artifact 10127702877) match main byte-for-byte.

Six of seven committed PNG files are invalid:
- hero_walk.png: 4,435 bytes; header 1024x128 but truncated IDAT. A header was previously mistaken for full validation.
- enemy_atlas.png: 179,490 bytes of malformed base64 text, not PNG bytes. Padding repair/decoding still fails PNG CRC/chunk checks.
- gothic_architecture.png: five bytes, not an image.
- gothic_castle.png and gothic_sky.png: invalid image signatures/data.
- gothic_playplane.png: header 512x195 but truncated IDAT.
- gothic_foreground.png: the ONLY valid PNG; 256x62, fully opaque, not a complete environment or transparent foreground.

The earlier dimension fix used the foreground's dimensions for the hero and play-plane dimensions for the enemy atlas. It was incorrect.

Historical browser evidence reproduces the production scene failing on the first enemy animation (Phaser getFirstTick, undefined duration) after failed texture loading. The sole valid opaque foreground was also enlarged about 11.6x and placed in front of characters. Those are separate failures.

The user's latest screenshot header matches recovery-1, which loaded the truncated hero, NOT asset-free recovery-2. The exact current recovery-2 source was independently tested in Chromium with both WebGL and Canvas: its colored diagnostic sprite, banner, movement and jumping work. The precise reason the older payload appeared in the user's browser remains unproven; do not assert that clearing a cache will fix it without checking that browser.

Root chain: index.html -> game/play.html?v=recovery-1 -> play.css?v=recovery-2 + Phaser 3.90.0 + runtime/recovery.js?v=recovery-2. No production modules are currently loaded by the root.

The original CSS forces both canvas dimensions to 100%!important, conflicting with Phaser FIT. The replacement lets Phaser own canvas sizing, at 640x360 logical resolution. Legacy prototypes and misleading milestone documents are not a production fallback.
